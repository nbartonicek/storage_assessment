2Set project policy

You know your projects better than the file dates do. Work down the list, starting with the projects that have the most to clean up (click any column heading to sort by it; click again to reverse). For each project: (a) set its status and whether it holds sensitive (patient, clinical or controlled-access) data, (b) add a note if useful, (c) tick Done, which keeps track of your progress and tells the data custodian which projects you checked. Every colour on the page follows your choices. Untick Show (or press only this) to focus steps 3 and 4 on some projects; all are shown by default.
